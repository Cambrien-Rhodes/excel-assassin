#Excel_Assassin v1.0 - Inventory Reorder Tool


**Why this**?  In 7 years of warehouse operations across 
2 or 3 sectors I encountered 1 problem they all had in common: stockouts.
Granted, they were rather smaller warehouses for the most part but still 
operating, supplying their customers with products and services they need.
Being that they were smaller, alot of the processes were manual, the only thing
digital about it was the fact that it was on Microsoft Excel.  As an employee, I 
seen managers shifting from spreadsheet to spreadsheet to create accurate reorder 
points for POs and it just seemed so time-consuming and draining.  It took hours often
and I feel as a manager your time could be better served doing something else than
sifting through spreadsheets.  This tool lessens the time spent on Excel, so said managers
can spend more time on the floor, using their abilities in a more productive, essential 
environment.

**What does it do?**  The "Excel Assassin" (beautifully named by the way) ingests CSV/Excel
spreadsheets and takes given thresholds to return an Excel File "assassinated.xlsx" that has
the given product name, bin location, sku, and current quantity on hand if they are below 
the given threshold. 

**Coming Features**  Adding Claude API Integration to return reorder summaries in Plain english, 
as well as the spreadhseet.
